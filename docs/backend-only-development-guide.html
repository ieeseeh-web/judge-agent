Judge Agent Backend 단독 실행 개발 가이드

judge-agent 프로젝트에서 frontend 없이 backend API만 별도로 실행하는 방법입니다.

파일 위치

  • 실행 스크립트: scripts/run-backend.sh
  • Markdown 문서: docs/backend-only-development-guide.md
  • HTML 문서: docs/backend-only-development-guide.html

Backend 구성

앱 모듈judgeagent.backend.api:app
기본 포트19001
기본 host0.0.0.0
로그 경로.logs/backend.log
PID 파일.logs/backend.pid
루트의 기존 start.sh는 backend와 frontend를 함께 실행합니다. backend만 실행하려면 ./scripts/run-backend.sh를 사용하세요.

기본 실행

./scripts/run-backend.sh
Backend:  http://localhost:19001
API Docs: http://localhost:19001/docs

포트 변경

BACKEND_PORT=19002 ./scripts/run-backend.sh

Host 변경

BACKEND_HOST=127.0.0.1 ./scripts/run-backend.sh

다른 장치에서도 접근해야 하면 기본값 0.0.0.0을 사용합니다.

Python 실행 파일 지정

PYTHON=.venv/bin/python ./scripts/run-backend.sh
source .venv/bin/activate
./scripts/run-backend.sh

의존성 설치

python3 -m pip install -e '.[api]'

agent 관련 의존성까지 필요하면:

python3 -m pip install -e '.[api,agent]'

로그 확인

tail -f .logs/backend.log

중지 방법

kill $(cat .logs/backend.pid)

프로젝트의 기존 ./stop.sh도 사용할 수 있습니다.

./stop.sh

reload 끄기

RELOAD=0 ./scripts/run-backend.sh

앱 모듈 변경

APP_MODULE=some.module:app ./scripts/run-backend.sh

정상 동작 확인

  1. backend 실행: ./scripts/run-backend.sh
  2. docs 페이지 확인: open http://localhost:19001/docs
  3. 로그 확인: tail -f .logs/backend.log

문제 해결

이미 실행 중이라고 나오는 경우

cat .logs/backend.pid
kill $(cat .logs/backend.pid)

uvicorn이 없다고 나오는 경우

python3 -m pip install -e '.[api]'
which python3
python3 -m pip show uvicorn

포트 충돌이 나는 경우

BACKEND_PORT=19002 ./scripts/run-backend.sh

frontend가 같이 실행되는 경우

./scripts/run-backend.sh

개발 체크리스트

  • 의존성 설치 완료
  • backend만 실행
  • http://localhost:19001/docs 접근 확인
  • .logs/backend.log 에러 확인
  • 작업 후 backend 종료
